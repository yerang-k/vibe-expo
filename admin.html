  1. Firebase 콘솔 → Firestore Database → 컬렉션 시작(또는 admins 컬렉션 열기)
  2. 컬렉션 ID: admins
  3. 문서 ID:
  4. 필드: name (문자열) = 아무 이름 → 저장
